# C++版
## 环境
安装[MingGW](https://sourceforge.net/projects/mingw-w64/)(C++/C的编译器)
{% hide 如果你之前用VisualStudio这样的IDE不需要编译器，是因为微软给你把编译器配好了，如果你还用过vscode、CLion就会发现，编译器的配置选项可以选VisualStudio的自带编译器 %}
## 创建文件
随便创建一个文件夹
往里面新建几个文件，注意后缀用令人熟悉的cpp和h，像这样--
![](https://fallingnight131.oss-cn-shanghai.aliyuncs.com/blog/image/20250308023518187.png)

## 编写文件
用一个文本编辑器(比如你的记事本)打开这些文件，然后简单编写一下：
{% codeblock lang:cpp %}
// main.cpp
#include<iostream>
#include"example.h"
int main()
{
	int a = 4, b = 8;
	example Ex(a,b);
	std::cout<<Ex.add();

}
{% endcodeblock %}
{% codeblock lang:cpp %}
// example.h
#include<iostream>

class example{
public:
	example(int a,int b);

	int add();

private:
	int A;
	int B;

};
{% endcodeblock %}
{% codeblock lang:cpp %}
//example.cpp
#include"example.h"

example::example(int a,int b):A(a),B(b){
	std::cout<<"Hello,I am initialized"<<std::endl;
}

int example::add(){
	return A+B;
}
{% endcodeblock %}

## 编译程序
### 用g++命令构建
然后在放这三个文件的文件夹里面输入：
{% codeblock lang:bash %}
g++ main.cpp example.cpp -o Example
{% endcodeblock %}
g++后面跟着的是项目里面所有cpp文件，用空格隔开。
-o 后面是可执行文件的名字
输入命令以后，在同一个文件夹里面，多了一个叫Example.exe的文件

### 用cmake构建
#### 编写CmakeLists文件
在根目录(放这三个文件的文件夹)创建一个叫CmakeLists.txt的文件，在里面写上例如：
{% codeblock lang:cmake %}
cmake_minimum_required(VERSION 3.28)
project(Example)

set(CMAKE_CXX_STANDARD 17)

add_executable(Draft main.cpp example.cpp)

{% endcodeblock %}
这样的指令

#### 配置命令
在根目录创建一个build文件夹，进入文件夹。
你可以直接通过
{% codeblock lang:bash %}
cmake ..
{% endcodeblock %}
配置项目，这样会以系统默认的生成器完成配置，如果你想要指定生成器(MinGW、VisualStudio、Ninja)和生成模式(Debug、Release),
可以通过：
{% codeblock lang:bash %}
cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug ..			//指定MingGW生成器,并使用Debug模式

cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release ..		//指定MingGW生成器,并使用Release模式

cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=RelWithDebInfo ..		//指定MingGW生成器,并使用RelWithDebInfo模式

cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=MinSizeRel ..		//指定MingGW生成器,并使用MinSizeRel模式

cmake -G "Ninja" -DCMAKE_BUILD_TYPE=Debug ..				//指定Ninja生成器,并使用Debug模式

cmake -G "Visual Studio 17 2022" -A x64 ..				//Visual Studio 的生成器不使用 CMAKE_BUILD_TYPE 变量，因为它们默认支持多种配置,可以在构建时指定配置

{% endcodeblock %}
等命令自定义生成方法(当然前提是你有安装过这些生成器，可以通过cmake --help命令查看你有哪些生成器)
![](https://fallingnight131.oss-cn-shanghai.aliyuncs.com/blog/image/20250308023643428.png)
Generators下面的信息会告诉你你安装过哪些生成器。

#### 构建命令
在build文件夹输入
{% codeblock lang:bash %}
cmake --build .
{% endcodeblock %}
命令构建，如果你用的生成器是visual studio生成器，可以指定构建模式：
{% codeblock lang:bash %}
cmake --build . --config Debug		//Debug模式

cmake --build . --config Release	//Release模式
{% endcodeblock %}

构建完成以后，在build文件夹(VisualStudio生成器是Debug或者Release文件夹)里会出现一个可执行文件，说明程序编译成功了。

{% tip warning 请确定你的项目文件夹的路径里面没有中文！ %} 
cmake压根就不认中文，有中文路径生成直接出错。

## 执行程序
![](https://fallingnight131.oss-cn-shanghai.aliyuncs.com/blog/image/20250308023606955.png)
用命令：
{% codeblock lang:bash %}
.\Example.exe
{% endcodeblock %}
运行可执行文件
![](https://fallingnight131.oss-cn-shanghai.aliyuncs.com/blog/image/20250308023723221.png)
于是程序的结果执行了出来。

# Python版
和前面C++一样，随便写点文件就行。
然后[创建一个虚拟环境](https://fallingnight131.cn/2024/10/14/pip%E5%91%BD%E4%BB%A4%E5%9F%BA%E7%A1%80/)，并将其激活。
假如最后程序从app.py开始运行，只要在命令行输入：
{% codeblock lang:bash %}
python app.py
{% endcodeblock %}
程序就可以执行了

由此不难看出，运行一个程序需要的是编译器(python是需要解释器),而不是IDE，但IDE该用还是得用，IDE上的许多功能(高亮、自动补全、自动跳转、错误警告等...)可以大大提高编写的效率。
